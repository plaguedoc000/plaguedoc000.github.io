# Расписание · Калужский филиал РАНХиГС

Telegram Mini App с расписанием 1 курса. Открывается по адресу
<https://plaguedoc000.github.io/>.

* `index.html` — само приложение. Трогать не нужно.
* `schedule.json` — **все данные расписания.** Правится отдельно от кода.

После сохранения `schedule.json` изменения появляются в приложении примерно
через минуту (столько GitHub Pages пересобирает сайт).

> **Важно:** не загружайте файлы через «Add file → Upload files» из папки
> «Загрузки» — браузер даёт им имена вида `index (1).html`, и сайт ломается.
> Правьте файл кнопкой ✏️ прямо в репозитории.

## Как устроен `schedule.json`

### `meta`

| Поле | Что значит |
|---|---|
| `org`, `course` | Подпись в шапке приложения |
| `semester` | Название периода. Только для людей |
| `yearStart`, `yearEnd` | Границы периода. Дальше них листать нельзя |
| `updated` | Когда последний раз правили. Только для людей |

Сейчас стоит первое полугодие: `2026-08-31` — `2026-12-31`. Когда выйдет
расписание на весну, поменяйте `yearEnd` и добавьте недостающие праздники.

### `groups`

Список групп в том порядке, в каком они идут кнопками вверху.
Названия должны **в точности** совпадать с ключами внутри `lessons` и `shared`.

### `pattern` — обычная неделя

Ключ — номер дня недели: `"1"` понедельник … `"6"` суббота.
Этот блок повторяется каждую неделю до конца периода.

```json
"3": { "lessons": { "ДМ-26": [ ...пары... ], "ДЭ-26": [ ... ] } }
```

или, если занятий нет:

```json
"6": { "notice": {"title": "День самостоятельной работы",
                  "sub": "Аудиторных занятий нет.", "tone": "rest"} }
```

Шаблон заполнен по расписанию на 07–12 сентября 2026.

### Одна пара

```json
{"num": 3, "start": "11:40", "end": "13:00",
 "subject": "Экономическая теория: Микроэкономика",
 "brief": "Микроэкономика",
 "teacher": "Косихина О.П.", "room": "503", "shared": "ДГиМУ-26"}
```

| Поле | Обязательное | Что значит |
|---|---|---|
| `num` | да | Номер пары, как в звонках |
| `start`, `end` | да | Время в формате `ЧЧ:ММ` |
| `subject` | да | Полное название. Видно при долгом нажатии на карточку |
| `brief` | нет | Короткое название для карточки. Нужно, если полное длиннее ~30 знаков |
| `teacher` | нет | Преподаватель |
| `room` | нет | Аудитория. Выводится как «ауд. 503» |
| `place` | нет | Адрес вместо аудитории. Вместе с `room` не ставится |
| `note` | нет | Приписка в строке сведений, например «1 подгруппа» |
| `shared` | нет | Группа, с которой идёт поток |
| `subgroups` | нет | Если пара делится на подгруппы, см. ниже |

Пары внутри дня должны идти по возрастанию времени.

### Подгруппы

Когда у пары несколько подгрупп с разными преподавателями и аудиториями,
вместо `teacher` и `room` заполняется `subgroups`:

```json
{"num": 1, "start": "08:30", "end": "09:50", "subject": "Иностранный язык",
 "subgroups": [
   {"label": "1 подгр", "room": "206", "teacher": "Вотинова О.Ю."},
   {"label": "2 подгр", "room": "502", "teacher": "Зельникова Я.И."},
   {"label": "3 подгр, начинающие", "room": "312", "teacher": "Пацина И.В."}
 ]}
```

Каждая подгруппа — отдельная строка в карточке. Номер и аудитория идут
первыми: на узком экране длинная строка обрезается с конца, и теряется
фамилия преподавателя, а не то, куда идти.

### `days` — конкретные даты

Перекрывают шаблон. Сюда пишут разовые события, замены и дни, которые
не должны меняться вместе с шаблоном:

```json
"2026-09-01": {"notice": {"title": "День знаний",
                          "sub": "«Народный дом», ул. Ленина, 74.",
                          "tone": "event"}}
```

`tone`: `event` — золотая карточка для событий, `rest` — приглушённая для
выходных. Точно так же сюда кладётся `lessons`, если в конкретный день
пары отличаются от обычной недели.

**Первая учебная неделя (31 августа — 5 сентября) закреплена именно здесь**,
поэтому смена недельного шаблона её не затрагивает.

### `holidays` — праздники

Ключ — дата, значение — строка или объект:

```json
"2026-11-04": "День народного единства",
"2026-12-31": {"title": "Выходной день", "sub": "Перенос новогодних каникул."}
```

Заполнено по производственному календарю РФ. Внутри первого полугодия
это 4 ноября и 31 декабря. Даты 2027 года оставлены в файле заранее — они
пока за границей периода и не показываются; 3 мая, 10 мая и 14 июня 2027 —
переносы по статье 112 ТК РФ (праздник выпал на выходной). Дополнительные
переносы новогодних выходных правительство утверждает отдельным
постановлением осенью 2026-го — когда оно выйдет, календарь стоит сверить.

### `breaks` — каникулы и сессия

**Пока пустой — эти даты нужно вписать.** Формат:

```json
"breaks": [
  {"from": "2026-12-21", "to": "2026-12-27",
   "title": "Зачётная неделя", "sub": "Расписание — на стенде."},
  {"from": "2026-12-28", "to": "2026-12-31",
   "title": "Зимние каникулы", "sub": "Занятий нет."}
]
```

Пока сессия и каникулы не заполнены, приложение показывает на эти дни
обычные пары из недельного шаблона, что неверно.

## Порядок разбора дня

Приложение берёт первое, что подошло:

1. `days` — запись на конкретную дату
2. `holidays` — праздник
3. `breaks` — каникулы или сессия
4. `pattern` — обычная неделя
5. иначе — «Расписание не заполнено»

## Проверить файл перед сохранением

Опечатка в JSON (лишняя запятая, забытая кавычка) роняет расписание целиком.
Перед коммитом вставьте файл в <https://jsonlint.com/> — он покажет строку с
ошибкой. Если файл всё же сломан, приложение покажет последнюю удачную версию
из кэша телефона и кнопку «Повторить».
